# Privacy Policy

Effective date: August 24, 2026

This policy applies to the ELI5 for Codex plugin maintained by 德荣 张 ([GitHub @zdrjson](https://github.com/zdrjson)) at [github.com/zdrjson/codex-eli5](https://github.com/zdrjson/codex-eli5).

## What the plugin does

The plugin supplies instructions and a local validation script that help Codex create self-contained HTML explainers. It has no MCP server, hosted backend, account system, analytics, advertising, cookies, or telemetry operated by the plugin developer.

## Information handled

The plugin developer does not receive or store your prompts, workspace files, generated explainers, or usage history. When a request refers to a specific codebase or document, Codex may read the files that you make available to it so it can answer accurately. Generated HTML is written to the workspace selected in your Codex environment.

The included checker reads only the HTML file you ask it to validate. It runs locally, makes no network requests, and does not send file contents to the plugin developer.

## Third-party services

Your use of Codex, ChatGPT, GitHub, or another platform is governed by that service's own privacy terms. Those services may process information independently of this plugin. This policy does not control their data handling.

## Your choices

Do not include secrets or personal information in a prompt or workspace unless it is necessary for your request and you are authorized to use it. You can inspect, edit, move, or delete generated HTML files like any other local workspace file. Uninstalling the plugin stops future use but does not delete files you previously generated.

## Changes and contact

Material changes will be recorded in this repository. For privacy questions, open a [GitHub issue](https://github.com/zdrjson/codex-eli5/issues) without including secrets or personal data.
